EndeavourOS + Hyprland on the SanDisk

Tick the boxes as you go. Cruzer = installer stick (E:). SanDisk 3.2 = where Linux goes (about 28.7 GB). Windows drive = about 954 GB, never touch it.

Part 1: Boot the installer

If it boots straight into Windows, restart and try F12 again, or pick the USB entry that says UEFI.

Part 2: Run the installer

If the summary shows the 954 GB drive, STOP and go back. That is your Windows drive.

Part 3: First boot from the SanDisk

Part 4: Install Caelestia (the Hyprland look)

Open a terminal (Konsole on KDE, or press Super + Enter in Hyprland). Run these one at a time:

sudo pacman -Syu
sudo pacman -S --needed hyprland xdg-desktop-portal-hyprland xdg-desktop-portal-gtk ttf-jetbrains-mono-nerd git base-devel
paru -S caelestia-cli
caelestia install

EndeavourOS includes yay. If paru is not found, run yay -S caelestia-cli instead.

If there is no Hyprland session in the list, or the screen is blank, switch to a text console with Ctrl+Alt+F3, log in, and run Hyprland to see any error message. Take a photo of the error.

Caelestia keys

  • Super (Windows key), press and release: launcher
  • Super + N: sidebar
  • Super + K: show all panels
  • Ctrl + Alt + Delete: session menu (log out, shut down)
  • Update later with caelestia update
  • Do not edit files in ~/.config/hypr/. Put your changes in ~/.config/caelestia/hypr-vars.lua and hypr-user.lua.

If something goes wrong

  • Installer fails or freezes: the SanDisk is the only thing it touches. Reboot the Cruzer and retry.
  • Nothing breaks Windows as long as you picked the 28.7 GB disk.
  • Take phone photos of any error, reboot Windows, and send them to Claude.
  • Caelestia install commands can change. If a step fails, check github.com/caelestia-dots/caelestia for the current steps.
